  # What is a pattern library? 

  A pattern library is a collection of reusable interface interaction patterns – like a component library, but for user experience flows. They're intended to be used as a living reference that you can borrow from when you're adding new features (and, by extension, new user experiences) to your software. 

  # Why does AI require new UX patterns? 

  AI comes with a whole new set of capabilities, but we're still figuring out the best way to expose those to users. Meanwhile, our users are approaching AI with no small amount of skepticism and distrust. To overcome that, we need to create a user experience that helps users understand what's happening, feel in control, and derive meaningful benefit from what we build. This library proposes a variety of solutions that you can add to your project to encourage comfortable user interaction with your new AI features. 

  # How do I use this? 
  Explore the patterns, play with the interactions, find the ones that work in your project, copy the code. No credit required; these are general patterns that are meant to be "stolen" and remixed. I built these using KendoReact UI components, but you can always recreate them with your component library of choice.
